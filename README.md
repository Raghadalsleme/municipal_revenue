# متابعة الإيرادات وأداء الأقسام — الإصدار 5.1

نموذج أولي بواجهة عربية لأمانة منطقة حائل. جميع الأرقام المرفقة بيانات تجريبية (Synthetic Data) وليست أرقام الأمانة الفعلية.

## ما تغير
- أسماء صفحات وتعليمات أبسط، مع الإبقاء على التحليل والتصدير.
- «استخدام الملف» يؤكد قبول الملف ويعرض اسمه، ثم يحدّث الإيرادات والفرص.
- «الرجوع لبيانات المثال» يعيد البيانات ويزيل الملف من خانة الرفع مع رسالة واضحة.
- أداء الأقسام في جدول بسيط مع ملخص شهري ومؤشرات دائرية وحالة مكتوبة بجوار اللون. أزيلت خلفية الصورة والزخارف.
- الأخضر: جيد (90% فأعلى)، الأصفر: يحتاج تحسين (70% إلى أقل من 90%)، الأحمر: يحتاج متابعة (أقل من 70%). يمكن تعديل الحدود، ويظهر الرمادي عند نقص البيانات.

## استخدام سريع
1. أداء الأقسام: اختر الإدارة والشهر، ثم افتح «تعديل أعداد المعاملات وأسماء الأقسام» لإدخال بياناتك.
2. إدخال البيانات: نزّل ملف المثال، عدّل الأرقام دون تغيير أسماء الأعمدة أو الأوراق، ارفعه ثم اضغط «استخدام الملف».
3. الإيرادات: تابع المستهدف والمحقق والمبلغ المتبقي.
4. فرص زيادة الإيرادات: راجع الفرص وأسبابها وحساباتها.
5. تجربة الفرص: اختر الفرص وقارن النتائج المتحفظة والمتوسطة والمتفائلة.
6. التقارير: نزّل النتائج بصيغة PDF أو Excel.

التعديلات تبقى في الجلسة فقط. احفظ ملفات Excel للاحتفاظ بها. بيانات أداء الأقسام مستقلة عن بيانات الإيرادات. ملفات الاستيراد تحتفظ بالأسماء التقنية لضمان توافق الملفات القديمة، وشرح الأعمدة داخل صفحة إدخال البيانات. لا توجد خدمة ذكاء اصطناعي خارجية؛ التحليل قواعد قابلة للتفسير. التفاصيل في docs.

## التشغيل على macOS
يلزم Python 3.11 أو 3.12. بعد فك ZIP افتح Terminal في مجلد municipal_revenue:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1
```

افتح http://localhost:8501. للإيقاف Ctrl+C. يلزم الإنترنت لتثبيت الحزم أول مرة فقط. بعد ذلك يعمل التطبيق دون اتصال. يمكنك بدلًا من الأوامر تشغيل `bash run_macos.command` من المجلد؛ يعيد التأكد من المتطلبات عند كل تشغيل. إن كان python3 قديمًا استخدم python3.12 لإنشاء البيئة.

## تجربة سريعة
1. لوحة الإيرادات: المستهدف 100,000,000 والمحقق 80,000,000 والفجوة 20,000,000 ريال، الإنجاز 80%.
2. اكتشاف الفرص: افحص أصل A01؛ 15,000 × 180 × 80% = 2,160,000 ريال إضافي سنوي، ثم يخفض الأثر بحسب مهلة التنفيذ والأيام الباقية.
3. تحليل السيناريوهات: أزل أو أضف فرصًا وانتقل بين متحفظ ومتوسط ومتفائل. تظهر الفجوة والفائض ويُفصل التحصيل لمرة واحدة.
4. التقارير: نزّل PDF عربي وExcel للسيناريو المختار. يحتوي Excel أيضًا المدخلات والنتائج وأدلة الفرص.
5. البيانات والمنهجية: نزّل القالب، عدّل المدخلات ثم ارفعه، أو ارفع ملفات CSV الأربعة. لا تخلط synthetic وreal. يعتمد الملف كاملًا فقط بعد اجتياز التحقق.

مثال عملي للتحقق من المحرك: غيّر occupancy للأصل A01 من 0.8 إلى 0.5 في ملف assets.csv، وارفع الملفات الأربعة. ينخفض تقديره السنوي من 2,160,000 إلى 1,350,000 ريال. الفرص ناتج حساب فعلي، وليست نصوصًا ثابتة في الواجهة.

## الوظائف المسلمة
- لوحة مؤشرات ومقارنة المستهدف بالمحقق ورسوم Plotly تفاعلية.
- محرك قواعد Pandas/NumPy لأصول شاغرة وتجديد عقود وتحصيل ذمم، مع الأدلة والمعادلات.
- تقدير سنوي وأثر في السنة الحالية بعد مهلة التنفيذ، ومعاملات حساسية محدودة بسقف.
- ترتيب وتوصية محفظة ومنع تكرار الفرص وتعارضها.
- صفحات مستقلة للسيناريوهات والتقارير والاستيراد عبر قائمة التنقل.
- تقارير PDF عربية بخط مضمّن، وExcel من Python. كل التصدير لقطة نتائج ثابتة؛ إعادة الحساب عبر التطبيق.
- تحقق صارم واستبدال ذري للبيانات، وتحييد صيغ Excel في النصوص المرفوعة.

## بنية الملفات
- `app.py`: واجهة Streamlit.
- `core/data.py`: مخطط البيانات والقراءة والتحقق.
- `core/engine.py`: حسابات الفجوة والاكتشاف والترتيب والسيناريوهات.
- `core/reports.py`: التصدير إلى PDF وExcel.
- `data/`: أربعة ملفات CSV تجريبية.
- `examples/`: قالب Excel وتقرير ونتائج وفرص مكتشفة للعرض.
- `docs/METHODOLOGY.md`: التقرير المختصر، المعادلات والقيود وخطة ML.
- `docs/DATA_DICTIONARY.md`: قاموس الأعمدة وقواعد الاستيراد.
- `tests/`: اختبارات الحسابات والتصدير والاستيراد وتفاعل الواجهة.
- `assets/`: خط DejaVu Sans ورخصته، فلا يلزم تثبيت خط عربي على Mac.

## تحديث النسخة السابقة
أوقف الخادم القديم بـ Ctrl+C، وفك ZIP الجديد في مجلد جديد حتى لا تختلط الملفات. اتبع التشغيل أدناه أو `bash run_macos.command` من مجلد المشروع الجديد. بياناتك السابقة التي صدّرتها إلى Excel يمكن رفعها من صفحة المجموعة المناسبة. المشروع لا يغير ملفات بيانات على جهازك تلقائيًا.

## الاختبارات وإعادة إنشاء الأمثلة
```bash
python -m pytest -q
python scripts_generate_examples.py
```
اختبارات الواجهة تستخدم Streamlit AppTest داخل Python. تفاصيل نتيجة التنفيذ في `docs/VALIDATION.md`. تم التحقق في بيئة Linux؛ لم يُجر اختبار على جهاز macOS فعلي. المكتبات ومسار الخط وسكربت التشغيل قابلة للعمل على macOS، ويظل اختبار القبول على جهازك مطلوبًا.

## النطاق المقصود لثلاثة أيام عمل
- يوم 1: بيانات والتحقق ومحرك القواعد واختبارات الحساب.
- يوم 2: لوحة وفرص وسيناريوهات واستيراد.
- يوم 3: تصدير واختبارات تكامل وتوثيق ومراجعة العرض.
هذه حدود نطاق النسخة، وليست ادعاءً أن التطوير استغرق ثلاثة أيام. لا تتضمن تكاملات إنتاجية أو نموذج ML مدربًا.

## قبل الاستخدام الفعلي
يحتاج اعتمادًا محاسبيًا لأساس النقد، أسعار سوق موثقة، مطابقة أرصدة وعقود وملكية وقيود، ومراجعة بشرية للموافقات. لا توجد مصادقة أو صلاحيات أو قاعدة بيانات أو سجل تدقيق؛ لا تنشره على شبكة عامة. البيانات في ذاكرة جلسة Streamlit ولا تُحفظ إلى القرص. الأساس التحليلي يفترض توزيع النقد على الأيام ولا يخصم تكاليف التنفيذ ولا يتنبأ بالإيرادات الاعتيادية القادمة.

لا تستخدم الفواتير التي سبق إثباتها كإيراد جديد على أساس الاستحقاق. لا تستخدم بيانات حقيقية حساسة قبل توفير بيئة داخلية معتمدة وضوابط التشغيل. خطة إضافة Scikit-learn وتقييم زمني موضحة في تقرير المنهجية، ولم يضاف نموذج صوري مدرب على البيانات المصطنعة.
